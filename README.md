# VAG MASTER Diagnostic PRO
Desktop Python/PySide6/SQLite starter for a VAG diagnostic knowledge base.

Included: GUI, SQLite, vehicle generations, starter DTCs, VAG module addresses, search, Windows PyInstaller build and GitHub Actions Windows build.

## EXE
On Windows run `scripts\build_windows.bat`.

## Important
This is an application foundation with starter data, not yet the complete 1996–2024 VAG workshop database. Model-specific repairs/coding must be validated before real vehicle use.
