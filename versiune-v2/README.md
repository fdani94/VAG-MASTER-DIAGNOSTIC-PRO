# VAG MASTER Diagnostic PRO — Versiunea 2

Acest dosar este spațiul de lucru pentru dezvoltarea aplicației V2.

## Obiective

- interfață profesională în limba română;
- selectare marcă, model, generație, an, motor și module;
- import și analiză Auto-Scan VCDS;
- explicații DTC, cauze probabile, verificări și pași de reparație;
- codări, adaptări, resetări service și proceduri ghidate;
- localizarea pieselor și generarea rapoartelor PDF;
- bază de date extinsă pentru Volkswagen, Audi, Škoda, SEAT și Cupra.

Creat la 20 august 2026 pentru dezvoltarea separată a versiunii V2.
