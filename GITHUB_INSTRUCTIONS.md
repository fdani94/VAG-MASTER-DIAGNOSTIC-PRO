# Upload to GitHub
Create repository `VAG-MASTER-DIAGNOSTIC-PRO`, then:
```
git init
git add .
git commit -m "Initial VAG MASTER PRO"
git branch -M main
git remote add origin https://github.com/USERNAME/VAG-MASTER-DIAGNOSTIC-PRO.git
git push -u origin main
```
GitHub -> Actions -> Build Windows EXE -> Run workflow.
Download artifact `VAG-MASTER-Diagnostic-PRO-Windows`.
